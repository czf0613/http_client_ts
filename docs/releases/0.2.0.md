# v0.2.0

This release fixes native Node ESM imports, makes timeouts cancel unfinished reads, and adds standard SSE parsing with errors that work with `for await` and `try/catch`. The library remains a zero-runtime-dependency Fetch wrapper.

## Changes

- Native ESM imports work directly from the installed package. Runtime regression tests use JavaScript and the compiled public entry, including an offline tarball installation check.
- HTTP requests support PATCH and external AbortSignal cancellation. Query parameters merge with existing URLs and preserve fragments; boolean query values are supported consistently.
- Request headers are copied and handled case-insensitively. FormData boundaries are generated by Fetch, and Blob, URLSearchParams, ArrayBuffer, typed arrays, and DataView retain their native body content.
- Timers and listeners are cleaned up on success, failure, and cancellation. All five timeout-enabled body readers cancel their own branch on timeout, while sibling clones can continue reading.
- Extended responses retain original status and redirect metadata, stable bound methods, coherent object properties, and extended clone support.
- SSE accepts LF, CRLF, and CR line endings, initial BOMs, comments, empty data, multiline data, and arbitrary UTF-8 chunk boundaries. Parsing is incremental, with a configurable 8 MiB event-size limit.
- GitHub Actions tests Node 22 and 24. Stable GitHub Releases publish to npm using OIDC Trusted Publishing after a fresh build and test run.

## Migration from 0.1.x

- Catch SSE failures with `try/catch`; failures now throw instead of returning a final `false`. Normal exhaustion still returns `true`.
- Do not manually remove the old extra separator space from SSE payloads. Only the protocol's optional single space is removed; multiline data is joined with newlines. Incomplete events at EOF are discarded.
- Use `0` to disable a timeout. Other values must be integer milliseconds from 1 to 2147483647. `messageTimeoutMs` still limits each individual stream read, not assembly of a complete event.
- Pass AbortSignal as HTTP argument 7 or SSE argument 8. External abort cancels the shared incoming stream; a body-read timeout cancels only the current clone branch.
- SSE argument 9, `maxEventBytes`, controls the event-size cap. The limit counts non-line-ending wire bytes, including ignored fields and comments; exceeding it throws and cancels the stream.
- Native response methods remain runtime-dependent. In particular, `bytesWithTimeout()` requires native `Response.bytes()` and has no fallback. ExtendedResponse does not promise native Response identity.

The release uses the existing API argument order, adds no OPTIONS convenience method or general RequestInit/HeadersInit parameter, and provides no server-side SSE writer or automatic reconnection.
